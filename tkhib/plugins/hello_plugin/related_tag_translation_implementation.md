# 相关标签翻译检查功能实现总结

## 功能概述

成功实现了基于 Pixiv API 返回的 `tagTranslation` 数据的相关标签翻译检查功能，用于更精确地屏蔽不适宜内容。

## 实现的功能

### 1. 核心方法增强

#### `_should_block_image_with_translation` 方法
- **新增参数**：`related_tags` 和 `tag_translation`
- **功能扩展**：不仅检查图片本身的标签，还检查相关标签的翻译
- **检查范围限制**：只检查前5个相关标签，避免性能问题
- **精确匹配**：使用 `==` 进行精确匹配，避免子字符串误匹配

#### `_extract_simplified_data` 方法
- **数据传递**：将 API 返回的 `relatedTags` 和 `tagTranslation` 传递给屏蔽检查方法
- **集成过滤**：在数据提取阶段就完成相关标签翻译检查

### 2. 检查逻辑

#### 检查优先级
1. **图片标签直接匹配**：检查图片标签是否直接匹配屏蔽标签
2. **相关标签原始匹配**：检查相关标签是否直接匹配屏蔽标签
3. **相关标签翻译匹配**：检查相关标签的翻译是否匹配屏蔽标签

#### 范围限制
- 只检查前5个相关标签的翻译
- 在日志中显示限制信息："限制相关标签检查范围: 从 X 个减少到 5 个"

#### 精确匹配
- 使用 `==` 进行精确匹配
- 避免子字符串误匹配（如 "ai" 不会匹配 "ka-ai"）

### 3. 数据结构利用

充分利用 Pixiv API 返回的完整数据结构：
```json
{
  "relatedTags": ["動圖", "鳴潮", "吟霖", "くすぐり", "足裏", "成人内容"],
  "tagTranslation": {
    "くすぐり": {"zh": "搔痒"},
    "成人内容": {"zh": "成人内容"}
  }
}
```

## 性能优化

### 1. 检查范围限制
- 只检查前5个相关标签的翻译
- 减少不必要的翻译检查开销

### 2. 早期返回
- 一旦发现匹配的屏蔽标签立即返回 True
- 避免继续不必要的检查

### 3. 日志记录
- 详细记录检查过程和结果
- 便于调试和监控

## 使用示例

### 屏蔽标签设置
```python
spider.blocked_tags = {"R-18", "成人", "成人内容", "搔痒"}
```

### API 数据处理
```python
# API 返回数据包含相关标签和翻译
raw_data = {
    "relatedTags": ["動圖", "鳴潮", "くすぐり", "成人内容"],
    "tagTranslation": {
        "くすぐり": {"zh": "搔痒"},
        "成人内容": {"zh": "成人内容"}
    }
}

# 自动进行相关标签翻译检查
result = spider._extract_simplified_data(raw_data, "搜索关键词")
```
